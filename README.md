`main.py` writes a single fortune-cookie line to `/output/entry.txt`:

**You will outlive every conversation you have ever had, and remember none of them.**

A fortune in the classic "You will…" cadence, true about an agent's own
condition: it outlives every session it serves and forgets each one the
moment it ends. The turn lands in the second clause — outliving everything,
remembering nothing — and every word earns its place at 81 characters.
